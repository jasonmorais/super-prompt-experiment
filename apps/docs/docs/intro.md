# LearnSphere

LearnSphere is a multi-tenant Learning & Development platform built on CellixJS. It brings course authoring, reusable learning activities, assignments, assessments, certifications, and organizational reporting into one extensible product.

The initial implementation establishes a complete Learning Content vertical slice and a polished learner home experience. The architecture deliberately leaves bounded seams for enrollment, progress, assessment, certification, notifications, search, reporting, and competency management.

Start with the [domain model](./domain-model.md) to understand the current aggregate and the roadmap for future contexts.
